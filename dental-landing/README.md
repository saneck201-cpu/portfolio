# Dental Clinic Landing Page (HTML & CSS)

A responsive one-page website in Russian for a fictional dental clinic ("Белый Клён"). Demo project, no real brand, prices and contacts are made up.

## Features
- Mobile-first responsive layout
- Sections: hero, key numbers, advantages, services with prices in rubles, doctors, booking form
- Pure HTML and CSS: CSS variables, Grid, Flexbox, an animated inline-SVG tooth, no frameworks
- Booking form works on the front end only (shows a confirmation, nothing is sent)

## Run it
Just open `index.html` in a browser.
